# AdventureWorks Sales Analysis using Python

## Project Overview
This project analyzes the **AdventureWorks sales dataset** to understand sales performance, customer behavior, product performance, and territory trends using Python.

## Analysis Performed

### Sales Analysis
- Total revenue, total orders, quantity sold, and average order value
- Monthly and yearly sales trends
- Weekday vs weekend revenue analysis
- Category and subcategory revenue analysis

### Customer Analysis
- Customer purchase behavior and engagement analysis
- Top customers based on revenue contribution
- Customer ordering patterns

### Product Analysis
- Category-wise and subcategory-wise revenue analysis
- Identification of top-performing products

### Territory Analysis
- Sales performance across different territories and countries

## Key Insights
- Compared revenue contribution between weekdays and weekends.
- Identified categories generating the highest revenue.
- Analyzed customer engagement based on purchase activity.
- Highlighted top-performing products and territories.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
AdventureWorks dataset containing sales, customer, product, and territory information.
